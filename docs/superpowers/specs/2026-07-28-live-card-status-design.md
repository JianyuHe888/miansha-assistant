# 主卡面动态体力与标记设计

## 目标

手机端阴阳鱼必须以可着色的文字图形显示，体力变化时主卡面同步更新当前/已损失状态。需要记录标记的武将在主卡面直接显示标记名称和当前数量。详情中的主武将牌可通过双击或手机双触切换翻面状态。

## 根因

- 当前 `☯` 没有文字呈现选择符，手机系统可能将其替换为彩色 Emoji，导致 CSS 颜色和失去体力样式失效。
- `HeroCard` 只读取武将数据中的印刷体力，`VitalityTracker` 的本局状态没有向上同步。
- 标记状态仅由 `SkillAssistant` 保存，主卡面既没有读取也没有接收状态更新。

## 方案

- 将阴阳鱼字符改为 `U+262F U+FE0E`，同时声明 `font-variant-emoji: text`，强制手机使用可着色的文字字形。
- `VitalityTracker` 在加载、修改和复原时把完整本局状态通知 `HeroDetail`；详情中的 `HeroCard` 使用该状态显示体力和护甲。
- `HeroDetail` 加载同一武将的标记存档，并接收 `SkillAssistant` 的即时更新。
- 新增主卡面标记组件：显示建议标记（包括数量为 0 的标记）以及玩家为“自己”添加的自定义标记；不显示其他座次的标记。
- 抽取结果和武将目录尚未进入本局时显示印刷初始体力与标记初始值；打开详情后切换为本局动态状态。
- 只有详情中的主卡面启用翻面交互。双击（触屏为双触）切换翻面/复原，状态按武将保存；翻面时以深色遮罩压暗全部原卡面内容，并在中央显示“翻面”字样。
- 卡面使用 `touch-action: manipulation`，避免手机双触被浏览器优先解释为页面缩放。

## 验收

- 手机浏览器不会将阴阳鱼替换为不可着色的彩色 Emoji。
- 点击受到伤害、失去体力、回复体力、调整上限或护甲后，主卡面立即同步。
- 在标记辅助中增减“自己”的标记后，主卡面立即显示“标记名 × 数量”。
- 其他座次的标记仍只在桌面标记台中显示。
- 双击详情主卡面可翻面，再次双击可复原；翻面状态关闭详情后仍保留。
- 所有单元测试、构建、渲染测试和代码检查通过。
