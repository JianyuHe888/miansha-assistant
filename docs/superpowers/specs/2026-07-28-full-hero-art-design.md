# 武将整张画像展示设计

## 目标

武将卡中的角色画像必须以原始宽高比完整显示，不再为了铺满卡面而放大、偏移或裁掉头顶、身体和武器等边缘内容。详情页继续维持较窄画像列和较宽信息列。

## 方案

沿用现有 `HeroCard` 和远程移动版武将图片，只调整统一的 `.hero-art` 样式：

- 图片铺设范围固定为完整卡面。
- 使用 `object-fit: contain` 保持原始比例和完整内容。
- 使用 `object-position: center bottom` 让不同尺寸立绘稳定落在卡面底部。
- 移除 `112%` 放大、负向水平偏移和仅占 `91%` 高度的裁切式布局。

该规则同时覆盖抽取结果、浏览缩略卡和详情卡，避免同一武将在不同入口显示方式不一致。图片比例与卡面比例不一致时，允许露出原有阵营背景；完整画像优先于无留白铺满。

## 验收

- 自动测试确认 `.hero-art` 使用全卡面尺寸、`contain` 和底部居中。
- 自动测试禁止画像宽度大于 `100%`、负向水平偏移或 `cover` 裁切。
- 原有信息区宽度、手机布局、体力和护甲功能测试继续通过。
- 构建、渲染测试和代码检查通过后，同步 GitHub 并部署至原 GPT Sites 地址。
